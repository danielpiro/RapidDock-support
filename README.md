# RapidDock support

RapidDock Integration sends Edge file downloads and magnet links to the RapidDock Windows download manager.

- [Privacy policy](PRIVACY.md)
- [Ask a question or report a problem](https://github.com/danielpiro/RapidDock-support/issues)

This repository contains public documentation and support discussions. The application's source code is maintained separately in a private repository.

Support issues are public. Do not post passwords, cookies, authorization headers, private download URLs, or other sensitive personal information.
